# Anti Slop Audit 001

Date: 2026-09-04  
Mode: AFTER  
Scope: Connections Pipeline Dashboard

## Design Read

The dashboard follows the declared operational workspace direction.

The Kanban board remains the primary workspace.

Warm surfaces, graphite controls, and cobalt actions match `DESIGN.md`.

Status rails communicate stage state.

No gradients, blur, or decorative card stripes appear.

The declared dials are ENERGY 2, RHYTHM 2, and MOTION 1.

## Findings

1. **HIGH, R-25: Closed KPI text has insufficient contrast.**  
   `#79818c` on `#fbfaf8` measures `3.78:1`.  
   Evidence: `app/globals.css:80`.  
   Repair: Use a text color with at least `4.5:1` contrast.

2. **HIGH, R-25: Empty notes text has insufficient contrast.**  
   `#7d8691` on `#f9f8f5` measures `3.47:1`.  
   Evidence: `app/globals.css:110`.  
   Repair: Use a text color with at least `4.5:1` contrast.

3. **HIGH, R-25 and R-32: Focus and control boundaries have insufficient contrast.**  
   The focus outline `#7aa0e8` measures `2.58:1` on `#fffdf9`.  
   Search borders measure `1.54:1` on white.  
   Dialog input borders measure `1.60:1` on white.  
   Evidence: `app/globals.css:23`, `app/globals.css:83`, and `app/globals.css:117`.  
   Repair: Use a `3:1` focus outline and control boundaries.

4. **HIGH, R-27: Dashboard loading and error states do not exist.**  
   Data errors throw from the dashboard server component.  
   The route lacks `app/dashboard/error.tsx` and `app/dashboard/loading.tsx`.  
   Evidence: `app/dashboard/page.tsx:10-15`.  
   Repair: Add useful loading and error states with recovery guidance.

5. **HIGH, R-26 and R-32: The profile edit dialog cannot close with Escape.**  
   `ConnectionForm` does not use `useDialogDismiss`.  
   Keyboard users must find the close button.  
   Evidence: `components/dashboard/connection-form.tsx:3-27`.  
   Repair: Add Escape dismissal and restore focus to the trigger.

6. **HIGH, R-32: Dialogs lack dialog semantics and focus containment.**  
   The batch, settings, profile, and message dialogs lack `aria-modal` and title linkage.  
   Focus can move to content behind each dialog.  
   Evidence: `app/dashboard/dashboard-client.tsx:187-202` and `components/dashboard/connection-form.tsx:19-27`.  
   Repair: Add `role="dialog"`, `aria-modal="true"`, labelled titles, initial focus, and a focus trap.

7. **HIGH, R-32: The card action menu lacks keyboard menu navigation.**  
   The menu has roles and Escape support.  
   It does not move focus into the menu or support arrow keys.  
   Evidence: `components/dashboard/kanban-board.tsx:84-122`.  
   Repair: Move focus to the first menu item and support ArrowUp, ArrowDown, Home, and End.

8. **HIGH, R-03: Several mobile card controls remain below 44 pixels.**  
   Quick links, Job Req, Copy Msg, and the action menu measure 28 pixels.  
   The mobile rules do not increase their touch targets.  
   Evidence: `app/globals.css:109-111` and `app/globals.css:119-120`.  
   Repair: Increase each touch target to at least 44 by 44 pixels.

9. **HIGH, R-03: The data table can clip on narrow screens.**  
   `.table-wrap` hides overflow around a seven-column table.  
   The mobile layout does not provide table reflow or scoped scrolling.  
   Evidence: `app/globals.css:114-115` and `app/globals.css:120`.  
   Repair: Use a mobile record layout or a scoped horizontal scroll container.

## Delivery Gate

### Hard Gate: FAIL

R-03 fails because controls are too small and the table can clip.

R-25 fails because audited text, focus, and control colors fail contrast requirements.

R-26 and R-32 fail because dialog and menu keyboard behavior is incomplete.

R-27 fails because dashboard loading and error states are absent.

### Purpose-Gate: PASS

The palette, status rails, elevation, and board scrolling have written purposes in `DESIGN.md`.

### Liveliness: PASS

The design uses the declared operational identity and dials.

It avoids generic decorative treatments.

### Craftsmanship and Quality Locks: FAIL

The dashboard fails resilience, keyboard access, contrast, and mobile usability checks.

## Verification Limits

The authenticated dashboard redirects to `/login` without a Supabase session.

This audit uses source review and contrast calculations.

It does not claim authenticated browser verification.
