# Connections design direction

This is a personal outreach operations workspace for one job seeker.

The interface is dense, warm, restrained, and operational.

The Kanban board is the focal point because stage movement is the primary task.

Use warm white surfaces, ink text, graphite controls, and cobalt only for primary actions.

Use status colors only to communicate pipeline state.

Use compact metadata and status rails as the identity motif.

Use no gradients, blur, decorative icons, or decorative card stripes.

Use cards only for contact records and opening records.

Use shadows only for menus and dialogs because they float above active work.

Use a humanist system sans-serif for dense operational text and reliable scanning.

Dial: ENERGY 2 / RHYTHM 2 / MOTION 1.

## Decision reasons

- Warm white reduces screen glare during long outreach sessions.
- Ink and graphite keep names, roles, and dates readable at compact sizes.
- Cobalt identifies committed actions without competing with stage colors.
- Status rails show workflow state without adding decorative color.
- The board stays horizontally scrollable because all five stages need stable comparison.
- Menus and dialogs use elevation because they require temporary focus above the board.
- Motion remains limited to feedback and drag targets because the data needs quiet scanning.
